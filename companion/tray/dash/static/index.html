Setup, limits & privacy

Add or import profiles through the Chrome extension. Connect here starts the service tunnel only: enable browser routing in the extension too. Disconnect here leaves any Chrome proxy rule in place, blocking proxied traffic until you turn it off in Chrome.

TCP proxy only, not a system VPN. No arbitrary UDP or Incognito. Local apps can use the loopback SOCKS port while active. WARP registration is optional, uses unofficial wgcf and requires agreeing to Cloudflare's terms in Chrome.

Windows installation, DPAPI and IPC are not yet runtime-verified. Do not rely on this preview for sensitive activity.
