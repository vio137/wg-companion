Setup & connection limits

Windows setup

  1. Run the Windows installer and approve service registration.
  2. In chrome://extensions, turn on Developer mode, choose Load unpacked and select the extension folder in the installed WireGuard Companion directory.
  3. Create a WARP profile or import a WireGuard .conf file.

This is a browser proxy, not a system VPN. It does not support arbitrary UDP or all Chrome services. Incognito is not supported. WebRTC non-proxied UDP and network prediction are disabled while enabled.

Only TCP proxy traffic is covered. QUIC/HTTP3 and WebRTC behavior depend on Chrome and are not a system-wide kill switch. VPN endpoint hostname lookups use your normal network to bootstrap the tunnel. Other local apps can use the loopback proxy while it runs.

The proxy stays enabled if the companion stops. Turn off here to restore direct browsing. Chrome startup, extension disable/removal, policy changes and other extensions are outside that protection. Existing connections may need a tab reload.

WARP uses the unofficial wgcf project. Cloudflare can change or block its API. No Cloudflare affiliation or guarantee.

Profiles are encrypted for your Windows user with DPAPI. Keep imported source files private. Do not paste keys into messages.
